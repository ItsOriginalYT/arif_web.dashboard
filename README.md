# Arif WebDashboard
A repository for a complete web dashboard for personal use.

ID: arif_web.dashboard

## Tools/API(s) used in this project
(Estimated)
Python: Backend programming
FastAPI: Web server, APIs and WebSockets
Uvicorn: Runs the Python web application
HTML5: Website structure
CSS3: Dashboard design and styling
JavaScript: Interactive dashboard functionality
SQLite: Accounts, messages, settings and history
OpenF1: Historical and authorized live F1 telemetry
Caddy: HTTPS and TLS certificates
pytest: Automated testing
